# Interface design standard and first refinement

The user's standing direction is that every UI should be clean, modern, user-friendly, intelligent, and beautiful. For PatchPulse this means readable evidence, visible provenance and limitations, simple exploration, and a coherent visual identity.

This refinement keeps a deep navy navigation area, warm coral actions, quiet paper backgrounds, and restrained green data accents. It enlarges previously tiny labels/body text, improves button contrast, softens card edges, and introduces an original pulse mark. No game art or external fonts are required.

The overview previews three records with a direct route to the complete evidence explorer. Filters show their current context and can be cleared together. The active navigation item is exposed to assistive technology, a skip link supports keyboard access, and all four mobile destinations fit without horizontal clipping. Zero-count aspect bars have no visible length; empty categories are omitted from the overview chart.

The data-mode warning, recorded-versus-predicted distinction, denominators, source-count discrepancy, and exploratory model limitations remain visible. Visual polish must preserve analytical honesty. Synthetic desktop/mobile screenshots document the result; source review text remains private. Browser tests cover the key interactions, reset behavior, overview density, and navigation visibility.
